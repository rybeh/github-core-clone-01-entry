A single-process, GitHub-compatible git forge written in TypeScript. One Node 22 process serves git over smart HTTP (clone, fetch and push), a GitHub REST v3–style API, a GraphQL endpoint, and an MCP interface, with all repository state created and managed by the process itself — no separate database or external services to run.

## Run it

```sh
node --experimental-strip-types main.ts
```
